# Nhut Nguyen — Portfolio

Personal portfolio built with Next.js (App Router), React, Tailwind CSS v4, Framer Motion and Three.js.

## Pages

| Route       | What it is                                             |
| ----------- | ------------------------------------------------------ |
| `/`         | 3D sphere of photos (Three.js)                         |
| `/about`    | Intro, photo collage, quotes and toolkit               |
| `/projects` | Projects with image decks                              |
| `/reise`    | Scroll-drawn trail through camping and hiking trips    |

## Editing content

Content lives in `lib/data/` — edit these files, not the components:

- `aboutData.ts` — About page text, collage and toolkit
- `projectsData.ts` — projects and their images
- `journeyData.ts` — Reise page stops and photos (images in `public/journey/<stop>/`)
- `archiveData.ts` — home sphere captions; the image list itself is generated by
  `python scripts/prepare_archive.py` into `archiveImages.generated.ts`

Full-size original photos are kept locally in `archive-originals/` (git-ignored).

## Development
